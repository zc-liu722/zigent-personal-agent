# 首版范围与支持状态

0.1 的维护重点是基础网页个人 Agent：持续对话、上下文与记忆、模型路由、交互输出和主动任务。高级集成暂以可选源码形式提供。默认配置和完整安装路径见 [安装指南](GETTING_STARTED.md)。

## 功能

| 功能 | 默认配置 | 当前准备状态 |
| --- | --- | --- |
| 网页登录、会话与流式对话 | 开启 | 核心范围；类型/编译通过，完整 HTTPS 登录及真实供应商对话待验收 |
| 会话历史、长期记忆、上下文整理 | 开启 | 核心范围；窗口和压缩方式依赖模型路线 |
| 官方 DeepSeek 模型路线及搜索 | 配置一条路线 | 使用用户自己的 API key，真实调用待用户环境验收 |
| 其他 API 供应商与模型选择 | 适配源码保留 | 需添加已核对的模型与供应商配置 |
| 子 Agent、用户确认、交互输出 | 开启 | 核心范围；实际行为由所选模型及用户操作决定 |
| 技能及主动任务 | 开启 | 核心范围；默认没有用户任务，持续运行和时区需由部署者维护 |
| 用量及费用记录 | 随运行时创建 | 供应商报告 token 正常保存；订阅路线货币费用为零 |
| 文档读取、编辑与文件交付 | 高级工具未开启 | 通用源码保留；需配置依赖和执行环境，分发许可待审核 |
| 通用命令与原生执行器 | 关闭 | Windows 原生执行为后续优先整理目标；安装、账户隔离和完整验收未完成 |
| 浏览器及托管浏览器 | 关闭 | 可选源码；需用户自己的浏览器环境和账号授权 |
| Google、Todoist、Notion、XMind、飞书文档 | 关闭 | 可选源码；各自授权、回调及供应商条款需确认 |
| 模型订阅登录与委派 | 关闭 | 可选源码；使用者自行确认客户端、登录及使用条款 |
| 语音、图像与视频 | 关闭 | 可选源码；需对应供应商配置及账号权限 |
| 健康、定位、手机通知和 Bark | 关闭 | 可选源码；需明确用户授权、设备接入和数据归属 |
| 跨机器项目空间同步 | 空登记表 | 仍有历史 Agent/Windows 约束，需进一步通用化，不列为首版正式使用路径 |
| 本地组件工作台 | 手动启动 | 仅用于本地开发；组件 AI 聊天需使用者自己的本地登录 |

“核心范围”是首版的开发维护承诺，不代表尚未执行的真实账号或全平台验收已完成。现有高级源码不会因为出现在清单中就自动连接或启用。

## 平台

| 平台 | 基础网页服务 | 高级执行 |
| --- | --- | --- |
| macOS | 首版目标；本地类型、服务端和网页编译已完成 | 可选源码；未准备完整本机执行器安装流程 |
| Linux | 首版目标；已提供 HTTPS 与可选 systemd 示例，实际主机验收待完成 | 容器/原生源码保留，镜像构建及分发审核待完成 |
| Windows | 首版目标；已提供 PowerShell 安装步骤，独立社区配置验收待完成 | 下一阶段优先整理原生执行；不复用个人生产主机 |

首版 Node.js 基线选 24 LTS；源码最低声明为 22.5。已在 macOS 上使用 Node.js 24.22.2 完成类型检查、服务端及网页编译和示例清单校验。这不代表实际供应商、完整登录或其他平台已通过验收。

## 单独构建

```bash
# 基础运行时与网页
npm run check
npm run build
npm run build:web

# 文档编辑器源码（可选，会重新生成 web/document-editor.js）
npm ci --prefix ops/document-editor
npm run build --prefix ops/document-editor

# 原生执行模块（可选；需要相应 Rust/MSVC 或系统编译环境）
cargo build --manifest-path ops/execution/native/Cargo.toml --release --locked --workspace
```

高级组件的源码、模型适配存在不等于完整安装流程或平台认证。打算对外正式支持的能力，应先补齐安装、授权、健康检查和维护说明，并更新这张表。
