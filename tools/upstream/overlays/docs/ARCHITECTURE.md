# 架构与可选能力

Zigent 面向可以自行部署和修改的个人 Agent。Big Context 包括持续积累的生活/工作上下文、会话和记忆；模型窗口只是实现的一部分。数据接入提供可查询证据，程序执行触发规则，模型结合上下文决定内容与行动。

## 默认运行路径

`src/index.ts` 从 `config/agents.json`（或 `AGENTS_CONFIG_PATH`）读取 Agent 清单，创建模型、会话、记忆、工具与网页运行时。`web/` 使用网页 HTTP/SSE 与认证操作接口。`data/` 保存本机产生的会话、网页状态与记忆，始终排除在 Git 之外。

示例 Agent ID 是 `assistant`，环境变量前缀为 `ASSISTANT`。模型采用完整的 family-version-supplier 路由身份，默认示例仅启用一条官方 API 路线，复用源码中记录的供应商上下文和推理档位元数据。

## Cordis 能力插件

[`PluginHost`](../src/plugins/host.ts) 使用 Cordis 管理服务依赖、初始化和释放。Zigent 宿主负责身份与权限、队列、资源授权、插件激活时机和执行恢复。插件通过版本化服务契约获取依赖，持久数据由宿主及各数据服务持有。

社区构建把日程、浏览器、文档、健康、定位、录音、模型适配器、文本模型目录和内置技能资源打包为不可变组件。网页静态资源单独生成版本包。`npm run build` 编译宿主，并根据 Git 跟踪的源码、锁文件、`config/agents.json` 和技能资源生成带内容摘要的包。`PluginInstallation` 校验包身份、内容哈希和宿主兼容性。

宿主先被动准备候选组件，再按组切换。新轮次使用当前版本，进行中的轮次持有其工具、服务、模型目录和技能资源快照。执行日志记录版本，恢复时尝试重新取得相同版本。权限由宿主继续校验，旧版本在调用和租约释放后才回收运行实例。

组件入口、服务和授权仍由仓库内的构建及宿主清单登记。社区版从本地构建产物装配组件。共享宿主代码、数据库格式和基础配置变更走宿主升级。通用插件安装、任意配置热切换及跨进程发布控制面属于后续迁移。

## 会话存储与执行恢复

`ConversationStore` 在 Agent 的 SQLite 库内以内容哈希保存不可变对象和引用，存放会话正文、工具结果、活动和检查点。历史与网页按消息和片段读取，网页数据库保存投影。待交付事件通过持久队列补齐投影。旧消息从兼容视图读取并分批回填。

`ExecutionJournal` 为每轮记录模型尝试、已提交的工具调用和结果、插件版本以及生成和交付状态。模型或整轮后续失败时，已提交的过程仍可恢复或供后续上下文读取。外部操作结果不确定时保留状态，避免恢复时重复执行。

升级前保留完整的 `data/`。新格式写入后，降级到旧程序需要停机，先用新版本的 `dist/conversation/maintenance.js hydrate-legacy` 还原旧格式，再启动旧程序。

## 长上下文与记忆

`src/models/` 负责请求适配、流式响应、上下文策略、压缩、供应商能力与用量。`src/memory/` 负责会话历史和持久化记忆。持续积累的个人上下文通过保存、查询和整理被后续任务使用；实际模型窗口仍以所选模型、供应商和运行时报告为准。

## 可选集成

账号授权、健康与定位接收、手机通知、语音、图像、视频、浏览器、项目同步、Codex/Claude 订阅适配等源码保留供审核与后续配置。没有导入个人授权、通知设备、存储桶、生产域名或登录缓存。示例不启用这些外部依赖。

## 文档与执行

文档解码 worker 位于 `ops/document-reader/`；编辑器源码位于 `ops/document-editor/`。通用执行 worker 与原生 Rust 模块位于 `ops/execution/`，文档库锁文件位于 `ops/file-runtime/`。高级执行需要独立准备环境、账户隔离和受控凭据。导出没有携带已有机器的安装、迁移、恢复和生产发布脚本。

项目登记表 `ops/project-spaces/projects.json` 默认为空。项目同步仍依赖单独配置的 Windows 工作目录和同步控制服务；它不属于默认示例的可用能力。不要将项目目录或生产账户信息直接写进公开配置。

## 第三方来源

原生模块的来源、版本和本地改动记录见 `ops/execution/native/UPSTREAM.md`。前端 KaTeX、highlight.js、Vaul 和文档编辑器的许可证随对应目录保留。完整项目许可证和依赖分发策略仍待维护者决定及审核，详见许可说明。
