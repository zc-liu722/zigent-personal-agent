# 通用能力与项目

能力描述“能做什么、怎么调用”；项目描述“要解决什么、用户承担什么、依据在哪里”。

- Codex 的通用委派能力位于 `src/codex/`，通过 `src/tools/codex.ts` 提供任务、会话、确认和执行入口，可用于多个已授权项目。
- 文档工具 `src/tools/documents.ts` 独立提供列表、读取、页图和检索，不要求项目。`documents/reader.ts` 与 `search.ts` 处理字节和片段；`service.ts` 协调已分享上传、确认导入和可选项目适配。来源权限由各自适配器核对，PDF／DOCX 解析不依赖某个项目。
- `src/project-spaces/` 是项目资源适配与权限层，负责目录、共享范围、owner、版本与项目背景，再把已授权内容传给通用能力。它不是能力说明的存放位置。

工具定义和能力文档维护调用方法；项目加载结果只包含业务背景、用户角色、资料入口和项目约束。项目可以简短引用适用能力，例如“需要修改项目文件时，可用 Codex 派发”，不复制工具使用手册。

复用文档能力不等于获得新的文件访问权限；新来源须由自己的适配器验证授权和版本。详细接口与现有接入见[文档能力](../../docs/ARCHITECTURE.md)。
